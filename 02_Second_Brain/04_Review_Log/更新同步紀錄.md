### SDT 函數官方簽名（逐字摘自說明頁，`_L` 版名稱加 `_L`，參數相同）

| 函數 | 語法 | 要點 |
| --- | --- | --- |
| `SDT_GetValue` | `SDT_GetValue(key, column, default:=0)` | 找不到 key／column 回傳 default；字串自動轉數值，失敗回 0 |
| `SDT_GetString` | `SDT_GetString(key, column, default:="")` | 數值自動轉字串 |
| `SDT_SetValue` | `SDT_SetValue(key, column, value)` | column 為不存在的字串即新增直行；欄號或直行總數超過 100 回傳錯誤 |
| `SDT_SetString` | `SDT_SetString(key, column, value)` | 同上 |
| `SDT_SetValueIf` | `SDT_SetValueIf(key, column, newvalue, oldvalue)` | 現值等於 oldvalue 才寫入並回傳 True，否則 False；可確保同時只有一個商品／策略寫入成功 |
| `SDT_SetStringIf` | `SDT_SetStringIf(key, column, newvalue, oldvalue)` | 同上，字串版 |
| `SDT_HasKey` | `SDT_HasKey(key)` | 回傳布林 |
| `SDT_GetKeys` | `SDT_GetKeys(output_key_array)` | 一維字串陣列輸出；key 順序不保證 |
| `SDT_Sum` / `SDT_Average` | `(column)` | 無法轉數值的列以 0 計入 |
| `SDT_Max` / `SDT_Min` / `SDT_Median` | `(column)` 或 `(column, output_key)` | 無法轉數值的列略過；同值取字串排序較小的 key |
| `SDT_SortKey` | `SDT_SortKey(sorted_key_array, order:=-1)` | order：**-1 由小到大（預設）、1 由大到小** |
| `SDT_Sort` / `SDT_SortString` | `(column, sorted_key_array, order:=-1)` | 依數值／字串排序；order 同上 |
| `SDT_RemoveKey` | `SDT_RemoveKey(key)` | 移除整列 |
| `SDT_RemoveAll` | `SDT_RemoveAll()` | 清空整張表 |
| `SDT_SetColumnName` | `SDT_SetColumnName(column_num, column_name)` | 命名或修改直行名稱 |
