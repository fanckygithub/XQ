# XQ 第二大腦

本資料夾是 XQ 專案的 Obsidian 知識庫入口，目標是把「策略想法、XScript 語法規則、可重用程式片段、錯誤修正紀錄」整理成可追蹤、可回查、可累積的工作系統。

## 使用原則

1. 先收集，再整理。
2. 先引用來源，再寫結論。
3. 策略想法與可執行 XS 程式碼分開保存。
4. 凡是涉及函數、欄位、語法規則，必須回到 `00_XQ_Manual` 核對。
5. 錯誤修正要留下原因、修正方式與避免重犯的規則。

## 資料夾用途

| 資料夾 | 用途 |
| --- | --- |
| `00_Inbox` | 暫存未整理的想法、文章、截圖摘要與待處理資料。 |
| `01_Knowledge_Base` | 整理後的 XScript 語法、函數、欄位、規則與案例索引。 |
| `02_Strategy_Lab` | 策略構想、金融邏輯、資料源假設、回測觀察。 |
| `03_Code_Snippets` | 已核對語法的可重用 XS 程式片段。 |
| `04_Review_Log` | 編譯錯誤、回測異常、修正紀錄與避坑規則。 |
| `99_Templates` | 固定格式模板，避免每次重新整理。 |

## 每次新增筆記的最低標準

- 有清楚標題。
- 有來源或判斷依據。
- 有狀態：`待整理`、`已核對`、`已實作`、`需複查`。
- 若包含 XS 語法，需註明已查閱的文件。
